# 📝 React To-Do List Application

A simple and yet elegant **To-Do List** built with **React** that stores tasks in memory during the session.  

---

## 🚀 Features

- ➕ **Add Tasks** — Quickly add new tasks to your list.
- ✅ **Mark as Completed** — Toggle tasks between done and pending.
- ❌ **Delete Tasks** — Remove tasks you no longer need.
- 📄 **In-Memory Storage** — Tasks are stored in React state (no backend or database).
- 🎨 **Clean UI** — Minimalistic and responsive design.

---

## 🛠️ Technologies Used

- **React** (Hooks & Functional Components)
- **JavaScript (ES6+)**
- **CSS** (or styled-components, depending on your implementation)
